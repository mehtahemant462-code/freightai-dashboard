# Development of an Intelligent Freight Forecasting Model

An AI-powered logistics solution developed for **Smart India Hackathon (SIH)** to forecast maritime freight rates and optimize vessel chartering & bulk cargo procurement for India's East Coast.

### Key Features

* AI-based freight rate prediction (7–30 days)
* Optimal vessel charter date recommendation
* Bulk cargo procurement cost optimization
* Weather & port congestion risk analysis
* Interactive analytics dashboard for decision support

### Tech Stack

**Frontend:** React, Tailwind CSS

**Backend:** Python, FastAPI

**AI/ML:** LSTM, XGBoost, Prophet

**Database:** PostgreSQL

> Built to help shipping and procurement teams reduce logistics costs through data-driven forecasting and intelligent decision-making.
